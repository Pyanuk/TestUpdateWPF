# Инструкция по настройке автообновления

## Что сделано:

1. ✅ Добавлен пакет `Clowd.Squirrel` (современная версия Squirrel.Windows)
2. ✅ Настроена проверка обновлений при запуске в `App.xaml.cs`
3. ✅ Добавлена версия 1.0.0 в проект
4. ✅ Создан скрипт `build-release.ps1` для сборки релиза

## Как использовать:

### 1. Восстановить пакеты
```bash
dotnet restore
```

### 2. Изменить URL обновлений
В файле `App.xaml.cs` замени:
```csharp
var updateUrl = "https://github.com/YOUR_USERNAME/YOUR_REPO/releases";
```
на свой GitHub репозиторий.

### 3. Создать первый релиз
```powershell
.\build-release.ps1
```

### 4. Загрузить на GitHub
1. Создай новый Release в GitHub (версия 1.0.0)
2. Загрузи все файлы из папки `Releases` в этот релиз
3. Опубликуй релиз

### 5. Для следующих версий:
1. Измени версию в `TestAutoUpdate.csproj`
2. Запусти `build-release.ps1`
3. Создай новый Release на GitHub с новой версией
4. Загрузи файлы

## Как работает:
- При запуске приложение проверяет GitHub Releases
- Если есть новая версия - показывает диалог
- После согласия скачивает и устанавливает обновление
- Создает ярлыки на рабочем столе и в меню Пуск
